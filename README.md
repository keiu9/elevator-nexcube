# NEXCUBE エレベーター体験

ビルのかご内で行先階、戸開・戸閉、呼出を操作する静的Webアプリです。1〜20階、50・100・150・200階、屋上（R）を選べます。ビルの階構成はゲーム用です。

## 起動・テスト

```sh
python3 -m http.server 8765 --bind 127.0.0.1
node --test tests/*.test.js
```

ゲームは `http://127.0.0.1:8765/`、音声検証は `/tests/audio.html`。音声検証のボタンを押すと全31録音をデコード・音量確認し、チャイム→20階→戸開を実再生して、同時に複数の案内が流れないことを確認します。

## 運行と操作

- 進行方向にある予約を近い階から処理し、その方向の予約がなくなってから反転します。走行中の追加予約は制動距離が足りる場合に取り込み、間に合わない階は折り返しで停車します。
- 閉扉完了後に加速し、巡航・減速・着床を経て停止します。1階分は4m相当、最高速度は10m/s。フレームレートによる挙動の差を抑えるため1/120秒以下の刻みで更新します。タブが非表示の間は走行を一時停止します。
- 到着後はチャイム、当該階の案内、戸開の順です。案内の終了を待って開扉し、戸開保持3.5秒後に自動戸閉します。「開」を押している間は開いた状態を保ち、閉じ途中にも反転できます。走行中の戸開操作は無効です。
- 予約階を450ms以内に2回押すと取り消せます。走行中の直近の停車先は保持します。「最初から」で音声と運行状態をリセットします。
- 非常呼出は外部に通信しないインターホン体験です。通常の行先予約や走行を取り消しません。

## 実装

`elevator.js` はDOM・音声に依存しない運行モデル、`audio.js` は録音と音声合成を直列再生するキュー、`app.js` は表示と操作です。音声の完了通知に世代番号を付け、開扉割り込みやリセット後に古い通知が動作を再開しないようにしています。

iPadでは操作イベント内でAudioContextを生成・再開し、録音をWeb Audioで再生します。各録音のRMS音量を調整し、ピークを0.85以下に制限します。録音を取得・デコードできない場合は日本語の音声合成へ切り替えます。`assets/chime/arrival.m4a` はこのアプリ用に合成した2音のチャイムです。
